# Akinator

Консольная реализация игры «Акинатор» на C/C++ на основе бинарного дерева решений.

## Возможности и режимы работы

При запуске программа предлагает 6 режимов:
1. **Угадать персонажа** — проход по дереву вопросов. Если персонажа нет в базе, Акинатор предложит добавить его вместе с отличительным вопросом.
2. **Показать дерево персонажей** — генерация и открытие графического дампа дерева с помощью Graphviz (`Dump_elems/dump.png`).
3. **Выдать определение объекта** — вывод цепочки признаков для выбранного персонажа.
4. **Сравнить персонажей** — поиск общих черт и различий между двумя объектами дерева.
5. **Выйти без сохранения** — завершение программы без перезаписи базы.
6. **Выйти с сохранением** — сохранение обновлённого дерева в файл `buffer.txt`.

### Дополнительные фичи
* **Отображение изображений:** при угадывании программа автоматически открывает фото персонажа из папки `Photos/` (если файл `<Имя_Персонажа>.jpg` существует).
* **Озвучка (Windows TTS):** синтез речи через PowerShell (`Microsoft Irina Desktop`). Включается раскомментированием `#define AKINATOR_SPEAK` в начале `akinator.cpp`.

## Структура проекта

* `akinator.cpp` / `akinator.h` — игровая логика, меню, определение и сравнение объектов.
* `tree.cpp` / `tree.h` — структура бинарного дерева, чтение и запись в файл.
* `tree_dump.cpp` / `tree_dump.h` — текстовый и графический (Graphviz) дампы.
* `stack.cpp` / `stack.h` — стек для построения пути от корня к персонажу.
* `buffer.txt` — файл базы данных дерева.
* `Photos/` — изображения персонажей.
* `Dump_elems/` — сгенерированные дампы (`.dot`, `.png`, `log.html`).
* `For_rubbish/` — временные файлы для озвучки и запуска картинок.
* `build.bat` — скрипт сборки.

## Требования и запуск

* **ОС:** Windows (используются WinAPI, PowerShell и `cmd`).
* **Инструменты:** компилятор `g++` (MinGW/MSYS2) и установленный **Graphviz** (`dot` должен быть добавлен в `PATH`).
